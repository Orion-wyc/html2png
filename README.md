**🌟 演示地址：** [https://itshen.github.io/html2png/demo](https://itshen.github.io/html2png/demo)

一个**轻量级、零依赖**的JavaScript工具，可以让任何网页快速获得导出PNG图片的能力。同时提供 **Chrome 浏览器插件**版本，支持在任意网页上使用。

## ✨ 特点

- **🚀 轻量级** - 单文件解决方案，不超过几KB
- **📦 零依赖** - 不需要任何第三方库（自动加载html2canvas）
- **🎯 即用即走** - 一行代码引入，无需配置
- **🎨 透明背景** - 导出的图片默认透明背景
- **📱 响应式** - 支持多种导出尺寸选择
- **🗜️ PNG 压缩优化** - 集成 UPNG.js，支持无损/256色/128色多种压缩模式
- **🔲 去除透明通道** - 非透明背景时移除 Alpha 通道，进一步减小文件体积
- **📐 自定义边距** - 支持为导出图片添加自定义边距
- **🧩 Chrome 插件** - 提供浏览器扩展版本，支持在任意网页上使用

## 🚀 快速开始

### 1. 引入工具

在HTML页面底部添加以下代码：

```html
<script src="html-to-png-exporter.js"></script>
```

### 2. 开始使用

页面加载完成后，右下角会自动出现控制面板，点击齿轮图标可配置导出参数，点击"开始选择"即可开始使用。

## 📋 使用步骤

1. **点击开始按钮** - 点击页面右下角面板中的"开始选择"按钮
2. **选择元素** - 鼠标悬停在想要导出的内容上（会显示蓝色边框）
3. **确认选择** - 左键点击高亮的元素进行导出；右键点击可切换到父级元素
4. **提前设置参数** - 导出前可通过齿轮图标打开设置面板，配置：
   - **背景类型**：透明、白底、原文档
   - **导出尺寸**：800px、1200px、1600px、1920px、原始尺寸
   - **压缩模式**：高质量（无损）、小体积（256色）、更小体积（128色）
   - **去除透明通道**：非透明背景时移除 Alpha 通道以减小体积
   - **自定义边距**：为导出图片添加自定义像素边距
5. **自动导出下载** - 选择元素后自动使用 UPNG.js 优化编码并下载 PNG 图片
6. **连续导出** - 下载完成后自动重新进入选择模式，继续选择下一个元素

## 🎯 功能特性

### 智能选择
- 鼠标悬停实时高亮预览
- 精确元素边界识别
- 支持任意HTML元素选择
- **右键选择父级元素** - 连续右键可逐级向上选择父级容器

### 灵活导出
- 多种尺寸预设选项（800px / 1200px / 1600px / 1920px / 原始尺寸）
- 高清2倍分辨率导出
- 透明背景 / 白底 / 原文档背景三种模式
- 自动文件命名（时间戳）

### PNG 压缩优化
- **UPNG.js 集成** - 自动加载 UPNG.js + pako 进行高级 PNG 编码
- **多种压缩模式** - 无损（lossless）、256色（lossy256）、128色（lossy128）
- **去除透明通道** - 非透明背景时移除 Alpha 通道，大幅减小文件体积
- **强制 RGBA 输出** - 透明背景模式下自动确保输出保留透明通道

### 自定义边距
- 可选开启自定义边距功能
- 支持 0-200px 的边距大小设置
- 边距背景自动跟随所选背景类型

### 用户体验
- 一键进入/退出选择模式
- ESC键快速取消操作
- 直观的视觉反馈（状态指示灯 + Toast 提示）
- 现代化UI设计
- **连续导出** - 下载完成后自动重新进入选择模式

## 🧩 Chrome 浏览器插件

项目同时提供 Chrome 浏览器扩展版本，可在任意网页上使用导出功能，无需修改网页代码。

### 安装方式

1. 地址栏输入 `chrome://extensions/` 打开扩展管理页面
2. 右上角打开"开发者模式"开关
3. 点击"加载已解压的扩展程序"，选择 `extension` 文件夹
4. 插件图标会出现在浏览器工具栏中

### 插件特点

- **即装即用** - 无需修改任何网页代码
- **设置持久化** - 导出设置自动保存到浏览器存储
- **状态同步** - 工具栏图标显示激活状态
- **CSP 兼容** - 内置 html2canvas、UPNG.js、pako，不受内容安全策略限制
- **完整功能** - 与脚本版本完全一致的导出能力和设置选项

### 插件使用方法

1. 点击工具栏插件图标，打开弹出面板
2. 在面板中配置导出设置（背景、尺寸、压缩模式等）
3. 点击"开始选择"，在页面上点击要导出的元素
4. 图片自动下载，可继续选择下一个元素

详细插件说明请查看 [extension/README.md](extension/README.md)

## 🔧 技术实现

- **纯JavaScript** - 使用原生ES6+语法
- **自动加载** - 动态引入html2canvas、UPNG.js、pako库
- **UPNG.js 编码** - 使用 UPNG.js 替代原生 toDataURL，显著减小 PNG 文件体积
- **事件驱动** - 高效的事件监听机制
- **样式隔离** - 不影响页面原有样式

## 📁 文件说明

- `html-to-png-exporter.js` - 核心工具文件（自动加载 html2canvas + UPNG.js + pako）
- `demo.html` - 功能演示页面
- `extension/` - Chrome 浏览器插件版本
  - `manifest.json` - 插件配置文件
  - `popup.html/js` - 插件弹窗界面及控制逻辑
  - `content.js` - 页面内容脚本（状态管理）
  - `background.js` - 后台服务脚本
  - `html-exporter-combined.js` - 插件版核心文件（内含 html2canvas + UPNG.js + pako）
  - `pako.min.js` / `UPNG.min.js` - PNG 压缩优化库
- `README.md` - 使用说明文档

## ⚠️ 注意事项

1. **网络要求** - 首次使用需要联网加载html2canvas、UPNG.js、pako库（CDN：jsdelivr）
2. **跨域限制** - 导出包含跨域图片的元素时可能受限
3. **浏览器兼容** - 现代浏览器（Chrome、Firefox、Safari、Edge）
4. **插件版本** - 浏览器插件版本内置所有依赖库，不受 CSP 和网络限制
